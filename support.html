Quick fixes

Most common

Dubbing AI not working in game / Discord

Go to your game or Discord's audio settings → Input device → select dubbingai Virtual Mic. The app must be running and a voice must be active first.

dubbingai Virtual Mic not showing up

Restart Dubbing AI as Administrator. If still missing, uninstall and reinstall — it installs the virtual audio driver on first run.

Voice sounds laggy or robotic

Lower your buffer size in Settings. Recommended: 128 or 256 samples. Also ensure no other apps are using 100% CPU.

App crashes on startup

Make sure you're on Windows 10/11 64-bit. Right-click the .exe → Properties → Compatibility → Run as Administrator. Try reinstalling if the issue persists.
